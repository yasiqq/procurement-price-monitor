# Scope проекта

## Цель
Платформа собирает рыночные котировки сырья (MOEX) и курс доллара (ЦБ РФ),
сопоставляет их с закупками предприятия, считает отклонения цены закупки
от рыночной и показывает аналитику по сырью, поставщикам и периодам.

## Сырьё и источники

| Сырьё | Тикер | Источник | Формат | Единица | Валюта | История с |
|---|---|---|---|---|---|---|
| Золото | GLDRUB_TOM | MOEX ISS (API) | JSON | грамм | RUB | 08.10.2024 |
| Медь | COPPER (непрерывный ряд) | CSV с сайта MOEX | CSV | тонна | USD | 08.10.2024 |
| Алюминий | ALUM (непрерывный ряд) | CSV с сайта MOEX | CSV | тонна | USD | 08.10.2024 |
| Курс USD | R01235 | ЦБ РФ (API) | XML | 1 USD | RUB | 08.10.2024 |

Единый период данных: с 08.10.2024 по сегодняшний день (около 2 лет).

Закупки не загружаются из внешнего источника, а генерируются скриптом
по реальным котировкам (с фиксированным seed для воспроизводимости).

## Особенности источников
- MOEX ISS: пагинация (до 100 строк на запрос), в истории золота нет объёма, только число сделок.
- ЦБ: десятичная запятая (93,2221), даты в формате ДД.ММ.ГГГГ, кодировка windows-1251,
  календарь не совпадает с MOEX (есть выходные, нет некоторых рабочих дней).
- Медь и алюминий: непрерывный ряд, склеенный сайтом MOEX из разных фьючерсов,
  на стыках контрактов возможны скачки цены. Склейку самостоятельно не делаем.
- Алюминий торгуется менее ликвидно, чем медь (много дней с малым объёмом).

## Правила
1. Нет котировки или курса на дату (выходной, праздник, разные календари):
   берём последнее значение до этой даты.
2. Единицы: грамм для золота, тонна для меди и алюминия, без пересчёта между ними.
3. Валюта: итоговое сравнение всегда в рублях.
   Рыночная цена в руб = котировка × курс ЦБ (для USD-инструментов).
   Конвертация выполняется один раз, в витрине (mart). В core хранится исходная валюта.
4. Для всех инструментов в core берём цену закрытия (CLOSE).
5. Закупки выражены в рублях за единицу сырья (грамм или тонна).

## Формулы
- отклонение_руб = цена_закупки_руб − рыночная_цена_руб
- отклонение_% = отклонение_руб / рыночная_цена_руб × 100

## Слои БД
- raw: данные как пришли из источников, без изменений
  - raw.moex_history: ответы ISS по золоту
  - raw.cbr_rates: курсы ЦБ
  - raw.moex_csv_quotes: строки из CSV по меди и алюминию
- core: очищенные и приведённые к единому формату данные
- mart: витрины для аналитики и API

## Вопросы аналитики
1. На сколько % в среднем закупки дороже или дешевле рынка, по каждому виду сырья?
2. Какой поставщик чаще и сильнее всех переплачивает?
3. Как менялось отклонение по месяцам (тренд, сезонность)?
4. Как курс доллара влияет на стоимость закупок меди и алюминия?
5. Какие закупки аномальные (отклонение больше N процентов)?
6. Сколько денег потеряно из-за переплаты за период (отклонение × объём)?
