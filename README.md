# Procurement Price Monitor

**Procurement Price Monitor** — это система для сбора, обработки и анализа цен на закупки из открытых источников (тендерные площадки, каталоги поставщиков). 

Проект призван закрыть следующие вопросы:
* Как менялась цена на конкретную категорию товаров во времени (тренды и сезонность)?
* Кто из поставщиков предлагает лучшие условия по конкретным позициям?
* Где наблюдаются аномалии в ценообразовании (подозрительно низкие или завышенные цены)?

### Архитектура (высокоуровневая)
* **ETL** — извлечение, очистка и загрузка данных из источников.
* **PostgreSQL** — хранение структурированных данных (в Docker).
* **API** — предоставление данных для внешних систем.
* **Frontend** — веб-интерфейс для просмотра дашбордов и отчетов.
